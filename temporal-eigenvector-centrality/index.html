Temporal Eigenvector Centrality

A high-performance C++ implementation with Python bindings for temporal and multiplex network centrality analysis.

Open on GitHub

Best for

Temporal and Multiplex Networks

Use it when entity ranking depends on how a network evolves over time rather than on a static graph alone.

Stack

C++ Core, Python Access

Combines a performant native implementation with a workflow-friendly Python interface.

What It Does

This project reimplements multilayer and temporal centrality methods in C++ and exposes them through Python bindings, making it easier to analyze larger temporal networks than a typical MATLAB workflow can handle comfortably.

  • C++14 implementation designed for sparse temporal network computations
  • Python wrapper for integration with data science workflows
  • Joint centrality, time-averaged centrality, and first-order mover scores
  • Support for giant component reduction on temporal graphs

Input Format

The edge list input is expected as a space-separated file with four columns:

source_node_id  target_node_id  weight  timestamp

Node IDs can be 0-based or 1-based. Timestamps are integer values such as years or ordered time steps.

Build And Install

mkdir build
cd build
cmake ..
make -j4

On Windows PowerShell:

mkdir build
cd build
cmake .. -DCMAKE_POLICY_VERSION_MINIMUM='3.5'
cmake --build .

Python Usage

import temporal_centrality as tc

net = tc.TemporalNetwork()
net.load_edge_list("path/to/edges.txt")
net.reduce_to_giant_component()

results = net.compute_joint_centrality(
    omegas=[1.0, 10.0, 100.0],
    type="authority"
)

Use Cases
