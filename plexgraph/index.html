Tool

plexgraph

A GPU-accelerated graph visualization library built for complex network types, where multiplex, temporal, and hypergraph networks are first-class rather than bolted onto a plain-graph model.

Read the docs Open on GitHub

Best for

Exploring Complex Networks Visually

Use plexgraph when your network has layers, time, or group interactions that a plain node-link view flattens away.

Stack

Python + GPU Viewer

Build graphs in Python and explore them in a browser tab or an inline Jupyter widget.

What It Does

plexgraph treats plain, multiplex, temporal, and hypergraph networks as variations of one underlying structure, so the same API and viewer work across all of them.

  • Directed edges, multiplex layers, temporal validity intervals, and hyperedges
  • GPU-accelerated interactive rendering
  • Styling encodings by degree, weight, attribute, or time
  • Export to PNG, JPG, SVG, HTML, and PDF

Supported Inputs

  • Edge lists and temporal edge lists
  • pandas DataFrames
  • networkx graphs
  • GEXF and GraphML files

Installation

pip install plexgraph

For the Jupyter notebook widget:

pip install "plexgraph[jupyter]"

To try a demo graph without writing any code:

python -m plexgraph demo

Example Usage

import plexgraph as pg

g = pg.Graph()
g.add_node("alice")
g.add_node("bob")
g.add_edge("alice", "bob", weight=2.0)
pg.show(g, node_color=pg.by_degree("plasma"))

show() opens a browser tab, or an inline widget inside a notebook.

Beyond Plain Graphs

g.add_layer("friendship")
g.add_edge("alice", "bob", layer="friendship")   # multiplex layer
g.add_edge("alice", "bob", t_start=0, t_end=5)   # temporal interval
g.add_hyperedge(["alice", "bob", "carol"])       # hyperedge

Interactive Viewer

  • Layer legend to toggle multiplex layers on and off
  • Timeline to scrub temporal graphs by moment, trailing window, or cumulative history
  • Flat, stacked-layer, and stacked-time views, plus a layer atlas and time ribbon
  • Filtering, neighbourhood focus, and path finding from the side panel
  • Density overview for views with more than 5,000 visible nodes
