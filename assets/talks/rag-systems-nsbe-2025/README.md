# RAG Systems at NSBE 2025

This folder is the recommended pattern for talk-specific assets.

Suggested contents:

- `hero.*` for the main image used on the detail page
- `photo-1.*`, `photo-2.*`, ... for event gallery images
- optional extra files such as thumbnails or poster images

The matching content entry lives in `assets/js/talks-data.js` under the slug `rag-systems-nsbe-2025`.
